SECTION 12: HELP! WHERE TO FIND ANSWERS

When I get stuck:

ERROR IN MY PYTHON CODE:
1. First: Google the exact error message
2. Then: Check Stack Overflow
3. Then: Ask ChatGPT
4. Then: Ask in Streamlit Community Forum
5. Last: Ask my teacher/supervisor

STREAMLIT NOT WORKING:
1. First: Check official docs at docs.streamlit.io
2. Then: Watch "Streamlit in 6 Minutes" on YouTube
3. Then: Post in Streamlit Community Forum

API NOT RESPONDING:
1. First: Check if internet connection works
2. Then: Verify URL/parameters are correct
3. Then: Check API documentation
4. Then: Test with simple request first

MODEL NOT ACCURATE ENOUGH:
1. First: Check if I have enough training data (100+ images per category)
2. Then: Verify data diversity (different angles, lighting)
3. Then: Try collecting more images of weak categories
4. Then: Retrain model
5. Remember: 70-80% is acceptable for MVP!

USER TESTING FEEDBACK DOESN'T MAKE SENSE:
1. First: Re-read their comments carefully
2. Then: Watch video recording of them using app
3. Then: Ask clarifying questions
4. Then: Document exactly what was confusing

RUNNING OUT OF TIME:
1. First: Cut features ruthlessly (focus on 1 working feature)
2. Then: Reduce scope (fewer food categories, simpler visualization)
3. Then: Prioritize documentation over perfection
4. Remember: Process evidence > Perfect product
